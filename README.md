# job-learn

2026 届秋招 · Java 后端方向复习仓库。

每天把学到的写下来，期末和秋招随时能检索。

## 怎么用

每天花 10 分钟做两件事：记笔记、存进度。

```bash
# 1. 进入仓库
cd job-learn

# 2. 记今天学了什么（Windows）
./scripts/daily.ps1

# 或者手动：在 daily/2026/09/ 下新建 2026-09-04.md，写完提交
git add -A
git commit -m "docs: 2026-09-04 复习日志"
git push origin HEAD
```

## 目录

| 目录 | 放什么 |
| --- | --- |
| `daily/` | 每日学习日志，按年月归档 |
| `notes/java/` | Java 基础、集合、并发、JVM |
| `notes/os/` | 操作系统：进程线程、内存管理、IO |
| `notes/network/` | 计算机网络：TCP/IP、HTTP、HTTPS |
| `notes/db/` | MySQL：索引、事务、锁、SQL 优化 |
| `notes/redis/` | Redis：数据结构、持久化、缓存三大问题、集群 |
| `notes/framework/` | Spring / Spring Boot / MyBatis |
| `notes/mq/` | Kafka / RocketMQ：可靠性、重复消费、积压 |
| `notes/distributed/` | 分布式：CAP、一致性、分布式锁、事务 |
| `notes/algorithm/` | 算法模板与套路总结 |
| `notes/system-design/` | 场景设计题：短链、限流、秒杀、红包 |
| `problems/leetcode/` | 刷题记录，一题一文件 |
| `interview/` | 面经，按「日期-公司-轮次」命名 |
| `projects/` | 项目复盘，STAR 结构，面试可直接讲 |
